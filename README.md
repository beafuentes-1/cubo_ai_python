# Cubo AI Python

Proyecto base para practicar tipos, estructuras y lógica en Python.

## Estructura

- `console/`: wrappers y utilidades para tipos básicos.
- `desktop/`: futura interfaz de escritorio.
- `web/`: futura interfaz web.

## Uso

```bash
python main.py
```

## Dependencias

Este proyecto inicial no requiere librerías externas.
